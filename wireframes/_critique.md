# Критика вайрфреймів — прискіпливий аудит

> Дата: 2026-07-02. Перевірено всі **28** сторінок `wireframes/*.html` проти
> [`_conventions.md`](_conventions.md), [`../concept/sitemap.md`](../concept/sitemap.md),
> [`../concept/flows.md`](../concept/flows.md).
> Метод: грепи (кольори / шрифти / тіні / іконки / заглушки / лінки / зони) + вичитка
> ключових стан-сторінок + headless-рендер.

## Дефекти за 6 категоріями

| Категорія | Знайдено | Деталі |
|---|---|---|
| Проліз вигляду (колір / шрифт / тінь / іконка / картинка) | — чисто | усі hex сірі (R=G=B); лише `system-ui`; ні `<svg>`/`<img>`/`@font-face`/градієнтів/радіусів |
| Заглушки (`lorem` / «Заголовок 1») | — чисто | усі `h1` — справжній доменний текст |
| Немає станів (з таблиці `_screens.md`) | — чисто | bank-connect та overview — по 4 стани; нові екрани — усі стани зі своїх флоу |
| Глухий кут (стан без виходу) | — чисто | `*-error` → «спробувати ще»; `*-empty` → дія; `*-loading` → «успіх + збій» |
| **Зона без головної дії** | **2** | `add-transaction.html`, `export.html` — нав-зона мала лінки, але без анотації дії |
| Екран не з карти | — чисто | усі 9 екранів присутні в `sitemap.md` |

> Хибний сигнал під час аудиту: `signin-error` / `transaction-edit-error` спершу здались
> без ретраю — то артефакт грепа (виходи є, але з класами `.btn-primary` / `.btn primary`,
> не `.btn`). Глухих кутів насправді немає.

## Що полагоджено

Пріоритет — глухі кути й відсутні стани першими. **Їх не виявлено**, тож виправляти першими
не було чого.

1. **Зона без головної дії** — `add-transaction.html`, `export.html`.
   - Було: `<span class="zone-label">Зона: глобальна навігація</span>`
   - Стало: `… Зона: глобальна навігація · головна дія: перехід між кластерами`
   - Тепер узгоджено з еталоном `overview.html` (кожна зона має підпис головної дії).

## Поза 6 категоріями — прийнято / на потім (не блокери)

- **Дрейф неймингу кнопок:** `.btn-primary` (signin) та `.btn primary` (transaction-edit)
  проти еталонного `.btn`. Усе сіре й робоче — уніфікувати на кроці **design-system**
  разом із токенами, щоб не чіпати робочу верстку зараз.
- **Інлайн `style="margin-top"`** у `categories.html` / `categories-empty.html` — нейтральний
  відступ (не колір/шрифт/тінь), grey-box не порушує; винести в CSS на кроці **tokens**.
- **`_screens.md`:** матриця станів документує лише 2 з 7 екранів (спадок кроків 06–07).
  Стани нових екранів виведені з `flows.md`; за потреби розширити матрицю.

## Підсумок

Мультиагентна генерація + централізована зшивка дали **узгоджений набір**: зони, нейминг зон,
навігація й лінки консистентні; жодного глухого кута, відсутнього стану чи прольозу кольору.
28 сторінок — усі екрани `sitemap.md` покрито, прототип клікається наскрізь.
