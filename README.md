# Бабосік

Особистий фінансовий менеджер. Автоімпорт з Monobank, ручне введення, категоризація, аналітика.

**Стек:** Next.js 14 · TypeScript · Tailwind CSS · shadcn/ui · Supabase · Vercel

### Вайрфрейми (`wireframes/`)

Клікабельний **grey-box** прототип усіх флоу — структура й зони, без кольору, шрифтів, іконок і тіней.

| Файл | Що тут |
|------|--------|
| [`wireframes/_conventions.md`](./wireframes/_conventions.md) | Правила вайрфреймів: grey-box, семантика, іменування, стани, ліве дерево |
| [`wireframes/_screens.md`](./wireframes/_screens.md) | Замовлення на екрани головного flow + матриця станів |
| [`wireframes/_critique.md`](./wireframes/_critique.md) | Прискіпливий аудит набору за 6 дефектами |
| `wireframes/*.html` | 28 сторінок: усі екрани sitemap × реальні стани; спільне дерево навігації (`wf-nav.js`) |

Прото клікається наскрізь: вхід → підключення банку → огляд → транзакції / правка → категорії → порівняння. Кожен стан має вихід; головні дії зв'язані за `flows.md`.

### Голос / текст продукту (`voices/`)

Як продукт говорить. Виведено з персон і мови конкурентів; застосовано до всіх 28 сторінок вайрфреймів.

| Файл | Що тут |
|------|--------|
| [`voices/docs/voice.md`](./voices/docs/voice.md) | Принципи голосу, словник (одне поняття — одне слово), заборонене |
| [`voices/docs/microcopy.md`](./voices/docs/microcopy.md) | Увесь текст інтерфейсу — **джерело правди**; наскрізна звірка «одна дія = одне ім'я» |

**Суть:** описуємо, не судимо · продукт робить роботу, а не наказ · довіра > дотепність · у помилці кажемо що сталось і що вціліло. Звертання **«ти»**; заборонені AI-кліше, оклики, емодзі, «успішно», мотиваційний тон.

## Дослідження

**Проведено:** аналіз 5 конкурентів, 4 JTBD, порівняння 5 UX-патернів.

### Ключові висновки

| Інсайт | Що робимо |
|--------|-----------|
| Користувачі хочуть автоматизацію + контроль | Monobank автоімпорт + ручне редагування |
| Стандартні категорії не підходять | CRUD своїх категорій і підкатегорій — MVP |
| Аналітика має читатись з першого погляду | Дашборд (Snapshot-first) — основний UX-патерн |
| Бюджети без даних виглядають зламано | Goal/Budget Contrast — відкладено на post-MVP |

### Конкуренти

| Продукт | Сильне | Слабке |
|---------|--------|--------|
| [Monobank](https://www.monobank.ua/) | Категоризація, дизайн | Немає кастомних категорій |
| [YNAB](https://www.ynab.com/) | Система бюджетів | Складно, дорого, англійська |
| [CoinKeeper](https://coinkeeper.me/) | Симпатичний UI | Застарів, мало автоматизації |
| [Spendee](https://www.spendee.com/) | Мультибанк, дизайн | Платне, не локалізоване для UA |
| Notion (самописний) | Гнучкість | Немає автоімпорту |

### UX-патерн для MVP

**Snapshot / Summary-first** — дашборд з агрегатами. Обраний тому що:
1. MVP-вимоги (аналітика по категоріях, топ витрат, порівняння місяців) — це і є дашборд
2. Агрегати кешуються → швидкість без спінерів
3. Десктоп як основний — дашборд масштабується природно

→ Детальний аналіз патернів: [`research/research.md`](./research/research.md)
