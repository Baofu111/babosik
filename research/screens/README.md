# Screens — референси конкурентів

Скріншоти зберігати тут. Формат: `productname_screen-description.png`

---

## Що знімати і звідки

| Продукт | Посилання | Що знімати |
|---------|-----------|-----------|
| Monobank | [monobank.ua](https://www.monobank.ua/) · [App Store](https://apps.apple.com/ua/app/monobank/id1282242398) | Екран аналітики, категорії витрат |
| YNAB | [app.ynab.com](https://app.ynab.com/) | Дашборд бюджетів, звіти |
| CoinKeeper | [coinkeeper.me](https://coinkeeper.me/) | Головний екран, додавання транзакції |
| Spendee | [spendee.com](https://www.spendee.com/) | Bubble chart, огляд витрат |
| Revolut | [revolut.com](https://www.revolut.com/) | Analytics tab, стрічка транзакцій |

## Naming convention

```
monobank_analytics.png
monobank_categories.png
ynab_dashboard.png
ynab_reports.png
coinkeeper_home.png
spendee_bubbles.png
revolut_feed.png
revolut_analytics.png
```

Після додавання скріншотів вони автоматично з'являться в [`research.html`](../research.html).
