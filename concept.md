## Напрями

Згенеровано три **різні мови** (не відтінки одного рішення), кожну показано власною мовою на
[`concept/directions.html`](concept/directions.html). Slop-тест пройдено двічі: жоден напрям не
вгадується з категорії — не money-green, не navy+gold, не крем/беж (first-order), і не
«фінтех-не-navy → термінал» (second-order).

**Спільний закон усіх трьох** (з `voices/docs/voice.md`): **колір ніколи не судить значення** —
жодних червоно-зелених на сумах. Акцент живе лише на дії, вибраному стані та сумі-герої; диски
категорій — окрема багатоколірна палітра. Семантичні кольори — тільки для *системних* станів
(підключення, помилка мережі), не для транзакцій.

### ✅ Обрано: Напрям 3 · Ясність

> **Рішення 2026-07-17.** Світла тема · стратегія **Full-palette** (3 ролі кольору) ·
> геометрія + гуманістика · іконки Solar **Bold**.
> Сцена: день, десктоп, фокус — впевнено читаєш картину за секунду.

| Атрибут | Рішення |
|---------|---------|
| Тема | світла (`#FBFBFA` тло) |
| Стратегія кольору | Full-palette: петроль (primary) + корал (accent) + золото (tertiary) |
| Primary | петроль `#0F5C57` — дія, вибраний стан, поточний таб |
| Accent | корал `#E8734F` — увага без присуду, контрапункт |
| Tertiary | золото `#E0A13C` — теги, дрібні підсвітки |
| Шрифти | **Bricolage Grotesque** (суми, заголовки) + **IBM Plex Sans** (інтерфейс) |
| Іконки | Solar **Bold** (заливка, впевнені) |
| Форма | радіуси 8–12px, чіткі тіні-елевація |

Повна специфікація живцем: [`concept.html`](concept.html) → далі стає входом для `tokens/`.

#### Синтез із референсом Magnific (рішення 2026-07-17)

Взято **прийоми, не клон** (`~/Downloads/photo_2026-07-17_20-21-55.jpg` — дашборд Magnific):
повітря, мʼякі washes під іконками, тихий низькоконтрастний сайдбар, дисципліна одного акценту.
**Гібрид дисків:** washes (`color-100` фон + `color-600` іконка) — навігація і вторинні плитки;
**насичені диски** лишаються на сигнатурних рядках категорій (основа Monobank). Нові пари
контрасту пораховано: petrol 6.2:1 · coral 4.9:1 · gold 5.0:1 (усі AA). Для AA на washes
`--gold-600` затемнено `#9C6A15 → #8A5E12`.
**Не взято** (клішé / конфлікт): ідентична сітка-плиток як герой, командний рядок-пошук,
велике вітання-момент («Good evening…») — вітання заборонене голосом (`voices/docs/voice.md`).
